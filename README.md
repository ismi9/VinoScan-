# VinoScan

Веб-додаток для аналізу винограду та рекомендацій щодо догляду за виноградником.

## Можливості

- Діагностика хвороб винограду
- Рекомендації з догляду
- База даних сортів
- Журнал спостережень

## Використання

Відкрийте `index.html` у браузері.

### Діагностика

1. Перейдіть на вкладку "Діагноз"
2. Завантажте фото листя
3. Отримайте результат аналізу

### База сортів

Шукайте сорти винограду за назвою у вкладці "Довідник".

## Технології


- HTML5 / CSS3
- JavaScript (Vanilla)
- Service Worker для офлайн роботи
